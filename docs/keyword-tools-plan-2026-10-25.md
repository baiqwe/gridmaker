## 每页产品设计

### 1. Pixel Grid：图片转网格参考

保留原 URL，避免迁移已有点击。建议 Title：Pixel Grid: Turn an Image into a Grid；H1：Pixel Grid。
首屏：图片上传和可用示例、网格预览、行列设置、保持方格比例、导出。
增强：裁剪与长宽比、对比不同格数、原图/结果切换、带线/无线 PNG。
明确区分格数与导出像素尺寸；导出显示实际尺寸与透明背景状态。
内容：真实原图到结果示例、24×18 与 24×24 的区别、清晰度/颜色损失及不适用场景。
FAQ：格子为何长方形、如何去掉网格线、是否上传文件、是否生成可编辑像素。
验收：比例计算正确、下载等于预览、手机可用、保留旧 canonical。

### 2. Easy Pixel Art Grid：跟着图案填格子

Title：Easy Pixel Art Grid: Draw Simple Patterns；H1：Easy Pixel Art Grid。
用户不必先上传。首屏默认打开一个原创简单图案及可填色的练习板。
功能：8×8/16×16、6–12 个原创图案、少量调色板、画笔/橡皮、撤销重做、参考显示开关、清空确认。
输出：完成图 PNG、空白练习格、参考答案图；打印需准确设置边距和尺寸。
图案用几何图形、花朵、水果等自创素材，不抓取受版权保护的角色。
正文围绕一个完整练习：选色、轮廓、对称、局部修正和结果，避免笼统 What/Why 重复。
FAQ：新手选多大、如何填错重来、如何打印、手机怎么操作。
验收：点击格子真能绘制，撤销覆盖绘制和清空，资源下载为真实作品。

### 3. Add Grid to Pixel Art：保留现有像素，只叠线

Title/H1：Add Grid to Pixel Art。
首屏：上传已完成的像素作品，显示源文件尺寸；默认不重采样、不改色。
功能：按像素指定 cell size、X/Y 起点、1px 线、主/次网格、背景透明度、整数倍无平滑缩放。
输出：带线作品、单独透明网格层；原图始终可恢复。
内容：放大后的单像素示例，解释为什么线偏移、如何处理非整数倍截图。
与 photo overlay 的边界：此页按真实像素对齐；照片页按比例分区。
验收：关闭线后像素与输入一致，透明像素保留，奇数尺寸边缘无丢失。

### 4. Pixel Art Grid：从空白画布开始

条件：只有真正支持逐格编辑时才发布，不能复制图片转网格页面。
Title：Pixel Art Grid: Draw and Export；H1：Pixel Art Grid。
功能：空白格、画笔、橡皮、填充、吸管、撤销、缩放、调色板、本地保存；首版不做动画和账户。
输出：原生分辨率 PNG、整数放大 PNG、可恢复项目文件。
与 easy 页边界：完整自由编辑 vs 有参考图的入门练习。
与 pixel grid 边界：手绘创作 vs 图片转换；需在搜索结果和 query×page 数据中再验证拆页价值。
验收：填充不漏边，缩放不改变内容，刷新恢复有效，透明导出准确。

### 5. Add Grid to Photo：完整照片叠线

保留 URL，core keyword 与 Title/H1 前部对齐。
增强：原图/网格切换、像素不变的 overlay 导出、网格线预设、坐标、可恢复设置。
内容：实际照片对照，讲解线色/不透明度对可读性的影响，明确不是多图拼贴工具。
不要另建 /grid-overlay、/add-grid-to-image 与之争抢同一任务。

### 6. Drawing Grid Maker：从照片转到画纸

首屏区别于普通叠线：输入纸张宽高和单位，设置参考图/画纸比例，裁剪或留白可选。
输出：带坐标参考图和对应空白纸张网格；明确打印缩放影响尺寸。
内容：一组带数字的转描案例，展示非等比画纸的处理方法、比例检查、分格临摹步骤。
默认较疏的网格；高密度坐标不得重复或遮挡主体。
验收：纸张与参考图坐标一一对应，打印示例经过实际尺寸检查。

### 7–8. 手作工具：后续开发门槛

十字绣 pattern 意图需要有限调色板、符号图例、格数和布目尺寸，不能仅靠叠线承诺完整 pattern。
钩针需要针密度、行高/针宽、成品尺寸演算；每格选色/逐行方向需明确。
优先升级已有 URL；不要先建一批只有文案的新工具页。

## 页面共同结构

1. 简洁导航、面包屑、唯一 H1、一句用途。
2. 首屏实际工具；特定页只呈现完成该任务的控件。
3. 真实结果对照、设置数值和可复现示例素材。
4. 操作步骤、输入/输出限制、故障排查、FAQ。
5. 2–3 个按下一步任务选择的内链、联系/隐私入口。

桌面：画布为主、右侧紧凑控件。手机：画布和控件顺序布局，必要操作条不遮盖内容；明确缩放与页面滚动区域。
每个页面 SSR 输出独有正文与 meta，编辑器按需挂载；下载、打印等依赖按点击加载。
共用图片/格子/导出基础模块，页面按功能配置，不按词生成同一个界面。

## 多语言

第一批优先英文和葡萄牙文。葡语像素相关证据：arte pixelada em grade 45 曝光/排名15.76、grade de pixel art 21/11.76、grade de pixel art fácil 18/19.72。
保留 /pt/grade-pixel、/es/cuadricula-pixel 已有地址，不因换核心词改 URL。
新 easy 页可用 /pt/pixel-art-facil、/es/pixel-art-facil；发布前检查语言自然度。
西语现有像素页49曝光/2点击/排名7.33，样本较小，应维护，不据此扩大量页面。
控件、校验、样例说明、FAQ 全部完成才发布相应语言，并只在 hreflang/sitemap 输出实际存在版本。

## 发布顺序与验收

- 第一批：旧 pixel 页深化 + easy 练习页 + 葡语对应体验。
- 第二批：精确像素叠线小试；根据使用数据决定是否扩展完整 editor。
- 第三批：绘画纸张映射、照片叠线；手作完整图纸等待资源与需求验证。
- 16×16、32×32 在本次可见查询中无记录；先作工具预设，不单独建页。
- 上线前核对异常路径301。三个月表中仍出现历史错误 URL，不代表现在仍返回200。
- 发布后按页看28天查询、点击、曝光和排名；同时跟踪工具开始/成功导出/导出失败，只记录非敏感参数，不记录图片或文件名。
- 若两页长期承接同一意图且功能无差异，合并内容并301；不按固定词密度或字数验收。
