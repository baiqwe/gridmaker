# Grid Maker

Free browser-based image grid tools for splitting social media posts, adding
drawing grids, making crochet grids, and previewing pixel grids.

Live site: https://anygridmaker.com

Core tools:

- https://anygridmaker.com/instagram-grid-maker
- https://anygridmaker.com/drawing-grid-maker
- https://anygridmaker.com/crochet-grid-maker
- https://anygridmaker.com/pixel-grid-maker
- https://anygridmaker.com/add-grid-to-photo
- https://anygridmaker.com/cross-stitch-grid-maker

## Stack

- TanStack Start
- React 19
- Tailwind CSS v4
- Cloudflare Workers

## Development

```bash
pnpm install
pnpm run dev
```

The local app runs at http://localhost:3000.

## Production

Production is configured for:

```txt
https://anygridmaker.com
```

Deploy with:

```bash
pnpm run deploy
```
